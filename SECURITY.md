# Security policy

## Reporting a vulnerability

Please report security issues in a [public GitHub issue](https://github.com/theangryangel/lfspla.net/issues).
Security reports are handled in the issue tracker; there is no private reporting
channel.

Include the affected component or commit, the impact, and steps to reproduce or
otherwise verify the issue. Add logs or a proof of concept when useful.

Do not include working credentials, session tokens, or other people's personal
data in an issue. Redact them from logs and examples. If a credential has been
exposed, revoke or rotate it and describe the exposure without reposting the
secret.
